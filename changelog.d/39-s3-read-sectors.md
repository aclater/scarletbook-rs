Changed
- **Breaking:** `Image::read_sectors` returns `Result<(), Error>` instead of `Result<bool, Error>`. A range past the image's last sector, formerly `Ok(false)`, is the new `Error::SectorRangeInvalid { lsn, count, sectors }`, and leaves the buffer as it was. An empty buffer, formerly `InvalidArgument`, reads nothing and succeeds for any `lsn` up to the sector count, as `sb_disc_read_sectors` does with a count of 0. It can't be deprecated first, since the name stays and only its return type changes. Most callers get a compile error; a caller that ignored the `bool` with `read_sectors(..)?;` now gets the error instead of unread data. The C ABI is unchanged. Migration: `docs/migrating-0.6.md`, S3 (#39, #303).
