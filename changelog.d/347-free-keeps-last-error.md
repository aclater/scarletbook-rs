Changed
- C ABI: the `_free` functions no longer clear or set the thread's last error message, so a C caller that frees its handles on an error path and then calls `sb_last_error_message()` gets the failed call's message instead of an empty string. This holds for a NULL handle and for a free refused because the handle is in use from a callback, which no longer leaves a message about the refusal. Only a panic caught inside a `_free` function still sets the message, as a bug report. `sb_last_error_message` is empty if the last call that returns a status succeeded. No signature changes; `SB_ABI_VERSION` stays 2 (#347, #PR).
