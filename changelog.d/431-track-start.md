Fixed
- A provisional reading (`SeekPolicy::Speculative`) of a range that begins at a track's first frame, opened from a seek index whose nearest seek hint lies before the track's start sector, now begins at the track's start LSN from the TOC when that sector's first frame record is at most the range's first frame, with the same single read call. Before, it began at the hint, which after a remount is often where the previous track's tail read began: 67,584 bytes of the previous track read again for each track head on sacdfs's plain DSD disc, 75,776 on the synthetic ones. Replaying sacdfs's head-then-tail call sequence on synthetic images, the reads with a loaded index fall from 25,751,552 to 19,636,224 bytes (0.6.2: 23,537,664) at the same 215 read calls, with the same frames. Positions stay provisional exactly as from a hint (specification 4, 4.2 item 8, which names track start LSNs as a way to choose the start); a hint with a saved confirmation is still preferred (#431, #PR).
