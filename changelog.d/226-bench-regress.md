Added
- A CI benchmark regression check: `.github/workflows/bench-regress.yml` builds `bench` and the scarletbook-pcm `callpattern` example from the base and the head, times single-threaded DST decoding, plain DSD to DSF and DSD to PCM alternately on one runner (a fresh copy of each program per run), and fails when the head needs more than 1.15 x the base's CPU time. It runs beside CI on pull requests that touch library sources, on main and nightly, and is not a required check (#226, #PR).
