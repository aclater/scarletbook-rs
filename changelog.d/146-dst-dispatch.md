Changed
- The DST decoder runs a build of itself with AVX2, BMI1, BMI2, LZCNT and MOVBE, chosen at run time, on x86-64 CPUs that have them, with output unchanged to the bit: a generic build now decodes DST as fast as an `x86-64-v3` build (a 50-minute 2-channel synthetic, all threads: 6.2 s against 7.3 s before). The generic C library gains it automatically; other targets and older CPUs keep the portable decoder. The core crate now denies `unsafe_code` instead of forbidding it, and allows it in one module, which only calls that `#[target_feature]` build of the safe decoder (#146, #PR).
