Added
- A benchmark kit for timing scarletbook on consumers' machines: each release publishes `scarletbook-benchkit-<version>-x86_64-linux.tar.gz` and its `-v3` (x86-64-v3) twin, with statically linked `bench`, `scarletbook-synth` and the scarletbook-pcm `callpattern` example, a machine-readable run list of the #224 cases (`benchmarks/runlist.json`) and a reference runner that prints one JSON line per timed run; pushes to main upload the same archives as workflow artifacts. A release now has 28 assets instead of 24 (`benchmarks/README.md`; #226, #PR).
- `benchmarks/RESULTS.md`: measured figures per release on a Zen 2 machine (3950X), generic and x86-64-v3 builds, with the method and the paths not measured; `benchmarks/compare.sh` reproduces them by timing two revisions against each other with the run list (#226, #PR).
