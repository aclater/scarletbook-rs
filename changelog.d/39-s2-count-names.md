Deprecated
- `AreaIndex::{checkpoints, hints, confirmations, pending_claims}`, which read like collections and return a count, are renamed `checkpoint_count`, `hint_count`, `confirmation_count` and `pending_claim_count`. The old names stay as deprecated methods, to be removed before 1.0; nothing breaks until then, except for builds that deny warnings. Before: `index.hints()`. After: `index.hint_count()` (#39, #299).
