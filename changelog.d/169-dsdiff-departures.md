Added
- DSDIFF departures D1 and D2 (specification 8, 8.7, at sacd-spec `e069569`), made only when named: D1 writes plain DSD's `CMPR` with `D = 20`, counting its pad byte; D2 writes `DIAR`, `DITI`, marker and comment text as ISO 8859-1, removing every other code point. A file written with either is not a conforming DSDIFF file. `scarletbook`: `OutputOptions::dsdiff_departures`, `with_dsdiff_departures` and `DsdiffDeparture`. `scarletbook-ffi`: options `SB_OUTPUT_OPTION_DSDIFF_DEPARTURE_D1` (35) and `SB_OUTPUT_OPTION_DSDIFF_DEPARTURE_D2` (36); `SbMarker` text is now written one byte per code point, and a code point above U+00FF is refused by `sb_output_options_add_marker` (#169, #187).
