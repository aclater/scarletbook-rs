Changed
- **Breaking, in small part:** `scarletbook_pcm::Cutoff::Default` is renamed `Cutoff::Standard`, the same filter with the same output bytes; `Cutoff::default()` and `SB_PCM_CUTOFF_DEFAULT` are unchanged. `Cutoff::Default` stays as a deprecated constant, to be removed before 1.0, so expressions and patterns on a `Cutoff` value still compile. What breaks now: `use Cutoff::Default` and `Cutoff::Default` in a pattern on a `&Cutoff` no longer compile, and `{:?}` of the filter prints `Standard`. Before: `PcmConfig::new(PcmRate::Hz176400, Cutoff::Default, 2)`. After: `PcmConfig::new(PcmRate::Hz176400, Cutoff::Standard, 2)` (#39, #291).
