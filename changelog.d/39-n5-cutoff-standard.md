Changed
- **Breaking, in small part:** `scarletbook_pcm::Cutoff::Default` is renamed `Cutoff::Standard`, the same filter with the same output bytes; `Cutoff::default()` and `SB_PCM_CUTOFF_DEFAULT` are unchanged. `Cutoff::Default` stays as a deprecated constant, to be removed before 1.0, so expressions and patterns on a `Cutoff` value still compile. What breaks now: `use Cutoff::Default` and `Cutoff::Default` in a pattern on a `&Cutoff` no longer compile, and `{:?}` of the filter prints `Standard`. Migration: `docs/migrating-0.6.md`, N5 (#39, #291).
