- Clarification for 0.7.0, no code change. From 0.7.0 on, `Layout::positions_for` gives only the positions of the DSF bytes asked for (#307, #390), not every position of the 4096 x C-byte rows they touch. A consumer that caches positions and fetches only those a request is missing can therefore make one more fetch, and one more seek, when a later request reads the rest of a row. sacdfs measured +3.6 % image reads and +7.9 % image bytes for the head and tail of every file of a 7,519-file library, with identical output. To fetch as 0.6.2 did, round each request out to whole rows of the sound data before calling `positions_for`; `docs/rust.md` gives the recipe (#431, #PR).
