Changed
- **C library: the shared library is now named after the C ABI on Linux and macOS, and ABI 2 is declared the 1.0 ABI.** The header and the ABI do not change, and archive names stay the same. In the archives, the Linux library is the file `lib/libscarletbook_ffi.so.2` with that SONAME, and the macOS one is `lib/libscarletbook_ffi.2.dylib` with the install name `@rpath/libscarletbook_ffi.2.dylib` and compatibility version 2.0.0; `libscarletbook_ffi.so` and `libscarletbook_ffi.dylib` are now links to them. **What a C consumer changes:** no source. A program linked against this release needs the versioned file at run time, so ship or install that file under that name, not only a file called `libscarletbook_ffi.so`. Programs loading the library by path, as with ctypes, keep working under the old name if the link is kept, and should move to the versioned one. On Windows nothing changes: `scarletbook_ffi.dll` keeps its name (#39).
